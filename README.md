# Gestão de Clientes

Projeto acadêmico da disciplina de **Programação Orientada a Objetos (POO)**, em **Java** com **Maven**, sobre um
sistema de gestão de clientes.

> **Estado:** repositório em fase inicial (estrutura Maven base). O código evolui ao longo do trabalho.
> Para a versão em API REST com Spring Boot e banco MySQL, veja o repositório
> [`api-gestao-de-clientes`](https://github.com/geandreac/api-gestao-de-clientes).

## Tecnologias

Java · Maven (wrapper `mvnw`).

## Como usar

Requisitos: **JDK** e o wrapper do Maven incluído no projeto.

```bash
# compilar
./mvnw compile        # Windows: mvnw.cmd compile

# empacotar
./mvnw package        # Windows: mvnw.cmd package
```

## Como clonar

```bash
git clone https://github.com/geandreac/Gestao-de-Clientes.git
cd Gestao-de-Clientes
./mvnw compile        # Windows: mvnw.cmd compile
```
